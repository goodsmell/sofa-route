# 소파 배송 동선표

한샘 소파 배송 고객을 정리하고, 방문 순서와 시간을 현장에서 수정하는 휴대폰용 PWA입니다.

## 실제 업무 순서

1. **출고표**에서 다음 날 배송 날짜를 고르고 담당자에게 받은 출고표 사진을 넣습니다.
2. **코스 짜기**에서 고객 시간, 빠른 이동, 균형 추천을 확인하고 한 코스를 선택합니다. T맵 앱키를 연결하면 추천을 처음 만들 때 세 코스의 도로 구간 시간도 함께 계산합니다. 고객 시간 추천은 Gemini 키를 연결하면 AI가 만들며, 키가 없으면 시간대·지역 규칙을 사용합니다.
3. **전화 확정**에서 고객 카드의 전화 버튼으로 통화하고 약속 시각이나 오전·오후 시간대를 수정합니다. 모두 통화 완료로 표시하면 배송 준비를 마칠 수 있습니다. 순서를 옮기거나 시간을 바꾸는 동안 T맵 구간 API는 자동 호출되지 않습니다. 필요할 때 **시간 계산하기**를 누릅니다.
4. 다음 날 **배송 시작**에서 **일 시작 · 지금 출발**을 누릅니다. 화면에 현재 집을 크게 표시하고 **도착**, **다음 집 출발**을 누른 실제 시각으로 이후 예상 방문 시간을 다시 계산합니다.

## 사용법

1. GitHub Pages 주소를 휴대폰에서 열고 홈 화면에 추가합니다.
2. 기본 출발은 그레이박스(경기 안산시 단원구 해봉로 232) 06:40, 복귀는 팔곡화물차고지(경기 안산시 팔곡산단1길 13)입니다. 필요하면 그날 상황에 맞게 수정합니다.
3. 담당자가 보낸 한샘 출고의뢰서 사진과 고객 목록 화면을 한꺼번에 선택합니다. 사진은 브라우저에서 OCR 처리하며 서버에 업로드하지 않습니다.
4. 출고의뢰서의 전체 주소로 코스를 자동 생성하고, 고객 목록 화면의 010 번호를 같은 이름의 고객에게 붙입니다. 의뢰서의 0508 안심번호는 별도로 보관합니다.
5. 아래 `배송 순서`에서 방문 순서와 예상 도착 시간을 먼저 봅니다. 고객 줄에서 바로 전화하거나 T맵에서 목적지를 찾습니다. 사진 인식 표시가 붙은 주소·번호·시간은 `정보 수정`에서 확인합니다.
6. 고객 카드를 열어 통화로 정한 시각이나 오전·오후를 바로 고치고 통화 완료를 표시합니다. 화면의 예상 시간은 즉시 바뀝니다.
7. 방문 순서를 끌어 바꾼 뒤 실제 구간 시간이 필요하면 `시간 계산하기`를 누릅니다. 다음 날 배송 화면의 `도착`과 `다음 집 출발`을 누르면 실제 시각이 이후 예상 시간에 반영됩니다.
8. 아래 `지도`에서 T맵 앱키를 연결하면 출발지, 방문지, 귀가 장소를 잇는 도로 경로를 볼 수 있습니다. 실제 폭·길이·적재중량·총중량을 입력하면 높이 3.40m와 함께 화물차 경로를 요청합니다.
9. 아래 `기록 달력`에서 날짜별 코스와 완료 시각을 다시 봅니다. 지난 날짜 기록을 하나씩 삭제하거나 지난 기록을 모두 삭제할 수 있습니다. 연결된 출고표 사진도 다른 날짜에서 쓰지 않는 경우 함께 삭제됩니다.
10. 고객 이름 옆 `출고표`를 누르면 그 고객의 원본 의뢰서 사진을 열고 확대할 수 있습니다. 예전에 사진 저장 기능 없이 넣은 기록은 해당 사진을 한 번 다시 넣어 연결합니다.
11. 고객 시간 AI 추천을 사용하려면 설정의 `AI 키 연결`에서 [Google AI Studio](https://aistudio.google.com/api-keys)의 개인 Gemini API 키를 입력합니다. `추천 코스 만들기`를 누를 때 추천을 새로 만듭니다. 키가 없거나 AI가 실패하면 시간대·지역 규칙을 사용합니다.

## 정확도와 비용

- AI 코스는 [Gemini 3.5 Flash-Lite](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite)를 사용합니다. [무료 등급](https://ai.google.dev/gemini-api/docs/pricing#gemini-3.5-flash-lite)의 사용량 제한 안에서는 입력·출력 요금이 없습니다. 유료 프로젝트 키를 넣으면 과금될 수 있으므로 무료 프로젝트 키를 사용하세요.
- AI에는 고객 이름·전화번호·원본 사진·상세 번지를 보내지 않습니다. 지역과 시간 조건만 Google에 전송합니다. 무료 등급의 입력 내용은 Google 제품 개선에 사용될 수 있습니다.
- 키를 앱 소스나 GitHub 저장소에 넣지 않습니다. 기본은 브라우저 세션에만 두고, `이 기기에 키 기억하기`를 선택한 경우에만 이 기기의 `localStorage`에 저장합니다. 이 기기를 함께 쓰는 사람이 있다면 저장하지 마세요.
- AI는 실시간 도로 거리와 교통을 조회하지 않습니다. 고객 누락·중복이 있는 답만 거절하고, 나머지는 AI 순서를 그대로 적용합니다. T맵에서 실제 이동 시간과 3.40m 높이 제한을 확인해야 합니다.
- AI 키가 없을 때는 오전·오후 시간대와 주소의 시·구를 묶는 규칙 기반 정렬이 작동합니다. 위치 좌표가 없어 실제 최단 경로는 보장하지 않습니다.
- 일반 소파 설치는 15분, 제품명에 `전동` 또는 `리클라이너`가 들어가면 30분을 기본으로 계산합니다. 특수 작업은 고객 수정 화면에서 설치 시간을 직접 입력합니다.
- 엘리베이터가 없거나 기존 소파 BS가 있으면 각각 15분, 스툴은 5분, 멀티유닛·모듈은 10분의 여유를 더합니다. 이 추가 시간은 임시 가정이며 현장 상황에 맞게 직접 수정할 수 있습니다.
- 배송 지도는 OpenStreetMap 바탕 지도에 T맵에서 받은 도로 경로를 표시합니다. 경로를 받으려면 [T맵 API 앱키](https://openapi.sk.com/)가 필요합니다. 키는 이 기기의 브라우저에만 저장하며 저장소에 넣지 않습니다. [T맵 API 무료 사용 한도](https://tmapapi.tmapmobility.com/terms.html)는 지오코딩 하루 2만 건, 다중 경유지 안내 30 하루 100건입니다. 실제 한도와 상품 상태는 앱키 계정에서 확인하세요.
- 차량은 3.5톤 화물차, 높이 3.40m입니다. 폭·길이·적재중량·총중량을 모두 입력하기 전 지도 경로는 차량 제한을 반영하지 않습니다. 입력 후에도 실제 운행에서는 T맵 화물차 설정과 현장 표지판을 확인해야 합니다.
- T맵 경로는 최대 30개 배송지를 지원하며, 사진에서 읽은 주소가 잘못되면 위치도 잘못 나옵니다. 지도에 쓰는 고객 주소는 T맵 API로 전송됩니다. 지도 경로는 이 브라우저에 장기 저장하지 않습니다.
- OCR은 무료 오픈소스 Tesseract.js를 사용합니다. 첫 사용에는 엔진과 한국어 언어 데이터를 내려받기 때문에 인터넷이 필요합니다. 작은 글씨와 흐린 사진은 반드시 확인해야 합니다.
- 고객 목록 화면처럼 주소가 잘린 사진만으로 배송지를 만들지 않습니다. 출고의뢰서 사진이 있어야 코스에 추가됩니다. 목록에서 연결되지 않은 010 번호는 화면에 개수를 표시합니다.
- 전날 연락, 늦은 방문 안내, 약속 시간 조율이 필요한 이유는 별도 상단 목록 대신 해당 고객의 방문 카드에 표시합니다.
- 날짜별 배송 기록과 완료 시각은 이 브라우저의 `localStorage`, 출고표 원본 사진은 `IndexedDB`에 저장됩니다. 다른 휴대폰과 자동 동기화되지 않으며 브라우저 데이터를 지우면 사라집니다. 저장 공간이 부족하면 사진이나 기록을 저장하지 못할 수 있습니다.
- 무료 GitHub Pages는 공개 저장소에서 사용 가능합니다. 고객 데이터나 출고의뢰서 원본을 저장소에 올리지 마세요.

## 개발

React와 Vite로 개발합니다. `web/src/App.jsx`에 화면과 상호작용, `web/src/logic.js`에 코스 계산, `web/src/ocr.js`에 사진 인식을 분리했습니다.

```bash
npm install
npm run dev
npm run build
```

`npm run build`는 배포용 파일을 저장소 루트의 `index.html`과 `assets/`에 복사합니다. GitHub Pages가 `main` 브랜치 루트를 서비스합니다.
