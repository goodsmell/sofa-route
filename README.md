# 소파 배송 동선표

한샘 소파 배송 고객을 정리하고, 방문 순서와 시간을 현장에서 수정하는 휴대폰용 PWA입니다.

## 사용법

1. GitHub Pages 주소를 휴대폰에서 열고 홈 화면에 추가합니다.
2. 기본 출발은 그레이박스(경기 안산시 단원구 해봉로 232) 06:40, 복귀는 팔곡화물차고지(경기 안산시 팔곡산단1길 13)입니다. 필요하면 그날 상황에 맞게 수정합니다.
3. 담당자가 보낸 한샘 출고의뢰서 사진과 고객 목록 화면을 한꺼번에 선택합니다. 사진은 브라우저에서 OCR 처리하며 서버에 업로드하지 않습니다.
4. 출고의뢰서의 전체 주소로 코스를 자동 생성하고, 고객 목록 화면의 010 번호를 같은 이름의 고객에게 붙입니다. 의뢰서의 0508 안심번호는 별도로 보관합니다.
5. 아래 `🚚 오늘 코스`에서 예상 도착·설치 종료·귀가 시간과 이동·설치·대기 시간을 봅니다. 사진 인식 표시가 붙은 주소·번호·시간은 `고치기`로 확인하고, 필요하면 순서를 위아래로 조정합니다.
6. 고객 카드에서 바로 전화하거나 T맵에서 목적지를 찾습니다. T맵에서 실제 이동 시간을 확인해 ±5분 버튼으로 수정하고, 배송을 마치면 `배송 완료`를 누릅니다.
7. 아래 `▦ 기록 달력`에서 날짜별 코스와 완료 시각을 다시 봅니다. 날짜를 눌러 당시 코스를 열 수도 있습니다. 파일을 따로 만들거나 보낼 필요가 없습니다.

## 정확도와 비용

- 현재 추천은 오전·오후 시간대와 주소의 시·구를 묶는 규칙 기반 정렬입니다. 실제 도로 거리, 교통 체증, 약속의 세부 시각을 최적화하지 않습니다.
- 순서 추천은 09~13시/13~17시 시간 범위 위반을 가장 크게 줄이고, 같은 지역을 묶는 점수 방식입니다. 먼 지역의 오전 방문, 분당·판교 10시 이후 방문, 팔곡화물차고지 복귀 방향은 보조 기준입니다. 위치 좌표가 없어 실제 최단 경로는 보장하지 않습니다.
- 일반 소파 설치는 15분, 제품명에 `전동` 또는 `리클라이너`가 들어가면 30분을 기본으로 계산합니다. 특수 작업은 고객 수정 화면에서 설치 시간을 직접 입력합니다.
- 엘리베이터가 없거나 기존 소파 BS가 있으면 각각 15분, 스툴은 5분, 멀티유닛·모듈은 10분의 여유를 더합니다. 이 추가 시간은 임시 가정이며 현장 상황에 맞게 직접 수정할 수 있습니다.
- 차량은 3.5톤 화물차, 높이 3.40m입니다. 현재 버전은 차량 높이·중량 제한 도로를 자동으로 걸러내지 않습니다. T맵의 화물차 차량 설정과 현장 표지판을 확인해야 합니다.
- OCR은 무료 오픈소스 Tesseract.js를 사용합니다. 첫 사용에는 엔진과 한국어 언어 데이터를 내려받기 때문에 인터넷이 필요합니다. 작은 글씨와 흐린 사진은 반드시 확인해야 합니다.
- 고객 목록 화면처럼 주소가 잘린 사진만으로 배송지를 만들지 않습니다. 출고의뢰서 사진이 있어야 코스에 추가됩니다. 목록에서 연결되지 않은 010 번호는 화면에 개수를 표시합니다.
- 날짜별 배송 기록과 완료 시각은 이 브라우저의 `localStorage`에 저장됩니다. 다른 휴대폰과 자동 동기화되지 않으며 브라우저 데이터를 지우면 사라집니다. 저장 공간이 부족하면 기록이 저장되지 않을 수 있습니다.
- 무료 GitHub Pages는 공개 저장소에서 사용 가능합니다. 고객 데이터나 출고의뢰서 원본을 저장소에 올리지 마세요.

## 개발

정적 HTML·JavaScript만 사용합니다. `index.html`이 배포 파일이고 `sofa-route.html`은 초기 시안 보관본입니다. 간단한 로컬 서버에서 `index.html`을 열면 서비스 워커도 확인할 수 있습니다.
